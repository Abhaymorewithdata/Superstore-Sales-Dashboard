# Superstore-Sales-Dashboard

📊 Superstore Sales Dashboard (Power BI)
This repository contains a Power BI template that visualizes sales data for a fictional superstore. It provides key insights into orders, profits, customer segments, regional performance, and product categories.

🧾 Features
Monthly Sales Analysis (with Month-Year formatting)

Profit Trends

Top Products by Sales & Quantity

Customer Segmentation

Geographical Sales Breakdown

Interactive Filters & Slicers
